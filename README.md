# 📱 Mobile Price Prediction Web Application

A professional **Machine Learning web application** that predicts the estimated price of a mobile phone based on its hardware specifications.  
Built using **Python, Scikit-learn, and Streamlit**, and deployed as a **SaaS-style ML app**.

## 📌 Project Overview

This project uses a **Linear Regression model** to estimate mobile phone prices based on key features such as RAM, storage, battery capacity, camera specifications, screen size, weight, and 5G support.

The primary goal of this project is to:
- Apply machine learning to a **real-world pricing problem**
- Build an **interpretable regression model**
- Deploy the model as a **production-ready web application**

---

## 🧠 Machine Learning Model

- **Algorithm:** Linear Regression  
- **Train R² Score:** ~0.79  
- **Test R² Score:** ~0.80  

The close performance on training and testing data indicates **good generalization** with minimal overfitting.
